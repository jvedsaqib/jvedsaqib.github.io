YouTube Bengali Comment Scraper

A Python Tkinter application for scraping Bengali comments from YouTube videos, saving them to JSON, and exporting to Google Sheets.

How It Works

1. Load Video Links

Upload a JSON file containing YouTube video URLs to start scraping.

2. Scrape Comments

The tool uses Selenium to scroll and scrape Bengali comments efficiently.

3. Save & Export

Save comments to JSON or export directly to a Google Sheet.

Demo Video

Uses

  • ✔️ Collecting Bengali YouTube comments for sentiment analysis
  • ✔️ Training datasets for NLP models
  • ✔️ Researching audience feedback on creators
  • ✔️ Automating repetitive YouTube data collection tasks

Features

Tkinter GUI

User-friendly interface for scraping and exporting Bengali YouTube comments.

ChromeDriver Integration

Easily choose ChromeDriver path and enable/disable headless mode.

Google Sheets Export

Save scraped comments directly to a connected Google Sheet.
